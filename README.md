# 🚀 AI Skill Library - Bahasa Indonesia

![Banner Placeholder](./screenshots/home.png)

Platform open-source untuk menemukan dan menggunakan AI coding skills tervalidasi — siap pakai untuk Claude Code, Cursor, Antigravity, dan AI Agent lainnya.

## ✨ Fitur Utama

- ⚡ **Instalasi 1 Perintah CLI:** Install skill langsung ke folder agent kesayangan kamu dalam hitungan detik via `npx skill-id add <name>`.
- 🛡️ **Tervalidasi & Lolos Pemindaian Keamanan:** Setiap skill melewati Zod schema check ketat, pengetesan performa, dan 20+ poin pemindaian potensi kelemahan keamanan.
- 🤖 **Kompatibilitas Multi-Agent Universal:** Format JSON & SKILL.md terstandarisasi yang siap dipakai di Claude Code, Cursor, Antigravity, Codex CLI, dan Gemini.
- 🇮🇩 **Instruksi Bahasa Indonesia Natural:** Didesain khusus dalam Bahasa Indonesia yang alami agar AI Agent dapat memproses instruksi dengan tingkat presisi maksimal.

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan teknologi modern untuk performa dan interaktivitas tingkat tinggi:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router) + React 19
- **Styling:** Tailwind CSS v4 + Shadcn UI
- **Animasi & Visual:** GSAP, Lenis (Smooth Scrolling), dan OGL (WebGL)
- **Database:** Drizzle ORM + Neon (Serverless Postgres)
- **AI Integrasi:** Vercel AI SDK (Anthropic, Google, Groq, OpenAI)
- **State Management:** Zustand + React Query
- **Autentikasi:** Next Auth v5

## 🚀 Panduan Memulai (Getting Started)

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/username/skill_bahasa_indonesia.git
   cd skill_bahasa_indonesia/app
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Development Server:**
   ```bash
   npm run dev
   ```

4. **Buka di Browser:**
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.
